# Week 2 Sales Data Analysis/ Data Collection & Nanagement

## 📊 Project Overview
This project analyzes a sales dataset using Python (pandas) in Jupyter Notebook.It also includes an excel report  
The objective was to clean the dataset and calculate key performance indicators (KPIs) to evaluate sales performance.

---

## 🛠 Tools Used
- Python
- Pandas
- Jupyter Notebook
- Excel (for final report)
- GitHub (for version control)

---

## 📁 Dataset
File used: `Week-2-Sales-Data.csv`

The dataset contains information about:
- Order Date
- Region
- Sales Representative
- Product
- Units Sold
- Revenue

---#Jupyter Notebook

## 🧹 Data Cleaning Steps
The following cleaning steps were performed:

- Removed duplicate records
- Checked and handled missing values
- Converted `Order_Date` column to datetime format
- Verified correct data types

---

## 📈 Key Performance Indicators (KPIs)

The following KPIs were calculated:

1. **Total Revenue**
2. **Average Units Sold per Order**
3. **Total Revenue per Region**
4. **Highest Revenue-Generating Sales Representative**
5. **Top 3 Products by Total Units Sold**

---

## 📊 Report
An Excel report (`Data Collection & Management.xlsx`) was generated summarizing:
- KPI results
- Revenue by region (with chart)
